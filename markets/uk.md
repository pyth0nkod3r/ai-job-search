# Market: United Kingdom (UK)

- **Languages:** English
- **Default CV language:** English
- **Portals:**
| Portal | Skill folder | Source | Notes |
|---|---|---|---|
| Reed | .agents/skills/reed-search | anjolok1997/ai-job-search-uk | public pages, robots-compliant, no API key |
| Totaljobs | .agents/skills/totaljobs-search | anjolok1997/ai-job-search-uk | path-only URLs; CLI refuses pagination past page 1 |
| Welcome to the Jungle | .agents/skills/wttj-search | anjolok1997/ai-job-search-uk | public JSON API |

- **CV conventions:** CV 2 pages max, no photo; education before experience for early
  careers; right-to-work question common — answer honestly once; salary in £, annual.
- **Notes:** the source fork ships an opt-in Sponsorship Gate that checks employers
  against the gov.uk visa-sponsor register — install it if you need sponsorship.
