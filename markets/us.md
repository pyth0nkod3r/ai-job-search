# Market: United States (US)

- **Languages:** English
- **Default CV language:** English
- **Portals:**
| Portal | Skill folder | Source | Notes |
|---|---|---|---|
| SWE List (SimplifyJobs) | .agents/skills/swelist-search | chenyuan99/ai-job-search (work branch) | new-grad/internship dataset |
| LinkedIn / freehire | built-in | this repo | |

- **CV conventions:** resume, not CV — 1 page (2 for senior); no photo, no age, no
  marital status, no photo; US recruiters expect quantified achievements and ATS-friendly
  single-column layout; do not include visa status unless asked (state work authorization
  plainly if needed, e.g. "authorized to work in the US").
- **Notes:** screening questions often ask US work authorization and salary expectations —
  the profile's deal-breakers should state authorization status once, clearly.
